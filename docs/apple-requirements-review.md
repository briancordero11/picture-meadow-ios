## Data handling the policy must describe

UserDefaults stores narration, voice-style, and remembering preferences, plus the draft only after opt-in. Voice selection uses available Apple English system voices and has no app speech-upload request or recording. Boy/Girl are higher-pitch adult voice styles, with actual voice/fallback shown and adult-only fixed-sample preview. Forget removes the stored preset and restores Woman. The draft includes topic, actions, setting, favorites, essential choice, and compatible older park fields. The yellow intake's Save favorites action keeps current-session preferences and returns to topics. It does not turn Remember choices on. Device backups may include saved settings. Board words clear on Finish, reset, and inactivity. AI images remain in RAM. An approved image can survive Finish/backgrounding in the current process, and clears on changed choices, discard, reset/Forget, or process termination.

A service code persists in Keychain and is accessible while unlocked, with no synchronization requested. It is separate from the server-only OpenAI key. Start a fresh wish preserves the remembering preference and service code. Forget removes local draft/words/images/preferences/code and revokes adult access. It cannot erase earlier backups, independent hosting/provider records, or sent support mail.

The legacy description endpoint sends four park-related fields and returns deterministic output. The direct image endpoint sends five catalog-ID fields to the operator, then an authored prompt to OpenAI. It sends no source-picture bytes, intake documents, photographs, board sentence, or child identity/medical fields. Connection metadata is exposed in transport. Backend code has no payload logger, image store, or wish DB, but temporarily retains socket-address counters. Actual hosting logs, locations, access, and retention remain unverified.

OpenAI standard abuse monitoring can retain request/output content. ZDR needs approved account/project configuration, which has not been established for this deployment. Publish the verified arrangement before activation. [OpenAI data controls](https://developers.openai.com/api/docs/guides/your-data).

Both native online flags default to off, with an empty API origin. The backend sample defaults generation/review off and has no provider key. An operator-review flag cannot enable ZDR. Assess OpenAI's under-18 safeguards against actual audience/data handling. [OpenAI under-18 guidance](https://developers.openai.com/api/docs/guides/safety-checks/under-18-api-guidance).
