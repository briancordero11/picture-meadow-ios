Using pictures to explore ideas

Wish Explorer helps a child and a grown-up explore interests, actions, settings, favorites, and a most-important idea using pictures. The picture journey has no fields for a child's name, birth date, address, photograph, health information, or account. It includes no advertising or analytics. The app does not request the camera, photo library, or microphone, and does not record audio.

The picture board, communication words, system speech, and local wish picture work without the optional online services. Online descriptions and AI picture generation are disabled in the default app build. Using them requires a configured service and the permissions below.

Choices, words, and images on the iPad

Current choices stay in memory. “Remember choices on this iPad” is off by default. If a grown-up turns it on, the app saves the topic, actions, setting, favorites, and most-important choice in local app settings. Older park, roller-coaster color, and animal choices may also be saved. Narration, voice-style, and remembering preferences are saved locally. Device backups may include those settings according to the device owner's backup configuration.

Grown-up voice preferences offer Boy, Girl, Man, and Woman styles using available Apple English system voices. Boy and Girl slightly increase an adult voice's pitch; no child voice recording is requested or stored. The app uses an Apple identifier compatibility allowlist and excludes custom-provider, personal, and novelty voices, shows the selected device voice and fallback, and offers an adult-only fixed preview. The app has no speech-upload endpoint, recording, or requested voice download. Forget choices resets the preset to Woman and removes its saved value.

The yellow favorites card opens optional choices before the wish topics. Save favorites returns to the topics and keeps those preferences with the current ideas, including when changing topics. It does not turn remembering on. Keeping choices across app launches requires the grown-up's Remember choices setting.

The talking-board sentence stays in memory. It is not written to preferences or included in an online request. It clears when the session finishes, the wish is reset, or the app becomes inactive. Speech uses the iPad's system synthesizer. Adult-gate answers and one-request permissions are temporary and are not saved or sent to the service.

Generated AI pictures and returned descriptions stay in memory. An AI picture needs grown-up review before appearing with the wish. Pending review pictures clear when grown-up access ends. An approved picture can remain in the current app process, including after returning home or switching away. Changing ideas, removing the picture, starting a fresh wish, or using Forget choices clears it. The app does not save AI pictures to Photos, preferences, a server gallery, or an image history.

If a grown-up enters a service access code, the app stores it persistently in this iPad's Keychain. It can be read only while the device is unlocked and is not synchronized to other devices. It is separate from the provider's API key, which stays on the operator's server.

Optional AI pictures

When AI picture making is configured, a grown-up passes the reading check, supplies service access, and sees the selected concepts, receiving service, and provider before confirming one request. The app sends five catalog-choice fields to the operator's service: topic, actions, setting, favorites, and most-important choice. It also sends the service access code in an authorization header. It excludes source artwork, intake documents, photographs, the talking-board sentence, and child identity or medical fields.

The service builds a prompt from catalog descriptions and sends it directly to OpenAI's Images API. OpenAI receives the prompt and generates a picture. The app receives that image through the service. The current implementation uses no AI routing intermediary. A grown-up reviews, approves, or discards the result. It represents an imagined idea for discussion.

OpenAI says API data is not used for training by default unless the API customer opts in. Default abuse-monitoring logs can retain prompts and outputs for up to 30 days, with longer retention for legal requirements or protecting services and others from harm. Zero Data Retention requires OpenAI approval and account/project configuration. No such approval or configuration has been established for this deployment. OpenAI API data controls.

The operator's service and hosting

The legacy online-description option sends the wish category, park, roller-coaster color, and animal choices after a separate one-request confirmation. It returns a description and deterministic illustration. That route does not call the AI provider, and the native app continues to draw its local picture.

The service processes request bodies, prompts, descriptions, and image buffers temporarily in memory. Its code has no wish database, image library, file uploads, or payload request logger. Its abuse-prevention limiter keeps a socket connection address, count, and expiry time in memory. At default settings, removal normally follows about 60–61 seconds after the first request in a window. Server suspension or a busy event loop can delay cleanup, so this is not an exact deletion deadline.

The host separately receives connection/request information, which can include IP addresses, times, paths, headers, and response status. Hosting logs, security records, backups, and provider processing follow the actual operator/account settings. Removing local data or withdrawing permission

  • Turn Remember choices off to remove the saved draft while keeping current choices in memory.
  • Start a new wish to clear current and saved choices, words, and generated pictures. The remembering, narration and voice preferences, and service access code remain available.
  • Remove an AI picture or remove AI service access in grown-up settings. Removing access clears its Keychain code and stops current requests. An already approved picture remains until removed or forgotten.
  • Forget choices on this iPad to turn remembering off, clear the draft, words, pictures and narration/voice preferences, remove the service code, and end grown-up access. This works offline.

Leaving grown-up settings or switching away cancels pending permissions and requests. A service may already have processed a request. Local clearing cannot recall that processing, erase separate provider/hosting records, or remove older backups. The app creates no user accounts. Forget does not send an account-deletion or provider-deletion request.

Support, privacy questions, and AI concerns

The privacy notice, privacy/data controls, app information, and AI-concern report are reached inside grown-up Settings after the four-digit reading check. There is no privacy link on the main header, pause screen, or code-entry screen. Once a real support email is configured, the app can open a mail draft containing a fixed concern selection and app version/build. It attaches no image, wish details, board words, access code, or child information. The grown-up decides whether to edit or send it. The app sends no report automatically and has no report database.

If you send an email, the publisher and its email provider receive your sender/reply address, the prepared concern and version, and anything you add. Please leave out a child's identity, photographs, medical information, and communication sentence.
